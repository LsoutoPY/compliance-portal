Glifo de ícone Lucide — use sempre que precisar de um ícone; nunca escreva SVG inline.

```jsx
<Icon name="shield-alert" size={18} />
<Icon name="trending-down" size={16} color="var(--text-negative)" />
```

Nomes em kebab-case do catálogo Lucide. Herda `currentColor`, então dentro de um botão ou badge basta não passar `color`.
