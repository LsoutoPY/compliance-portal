Botão de ação — uma `primary` por tela; todo o resto é `secondary` ou `ghost`.

```jsx
<Button icon="download">Exportar parecer</Button>
<Button variant="secondary" icon="filter">Filtros</Button>
<Button variant="ghost" size="sm" iconRight="chevron-right">Ver safras</Button>
<Button variant="danger" icon="octagon-alert">Bloquear cedente</Button>
```

Rótulos em frase, verbo no infinitivo ("Exportar parecer", não "Exportação"). Altura 36px (28 em `sm`, 44 em `lg` — use `lg` no mobile).
