Botão só de ícone para barras de ferramentas, cabeçalhos de card e ações de linha.

```jsx
<IconButton icon="refresh-cw" label="Atualizar dados" />
<IconButton icon="star" label="Fixar fundo" pressed />
<IconButton icon="ellipsis-vertical" label="Mais ações" size="sm" />
```

`label` nunca é opcional. No mobile use `size="lg"` para respeitar o alvo de 44px.
